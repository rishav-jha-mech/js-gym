# JS Gym 🏋️‍♂️

A personal gym for **Data Structures & Algorithms in JavaScript**.

I'm building this repository from scratch to practice DSA, strengthen my problem-solving skills, and get better at technical interviews.

No copy-pasting solutions. No blindly grinding LeetCode.

The goal is to **understand the data structure, implement it myself, test it, break it, fix it, and then use it to solve problems.**

## 🧠 What I'm Practicing

* Arrays
* Strings
* Hashing
* Stacks
* Queues
* Linked Lists
* Trees
* Binary Search Trees
* Heaps / Priority Queues
* Graphs
* Recursion
* Backtracking
* Greedy Algorithms
* Dynamic Programming
* Advanced Graph Algorithms
